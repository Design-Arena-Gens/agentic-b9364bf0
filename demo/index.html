🚀 Quick Start

1. Install Dependencies

npm install

2. Set API Keys

export ANTHROPIC_API_KEY="your-key-here" export OPENAI_API_KEY="your-key-here"

3. Build Extension

npm run build

4. Use in VS Code

1. Open Command Palette (Cmd+Shift+P) 2. Run: "Start Autonomous Architect" 3. Enter your task: "Create a REST API with authentication" 4. Watch the magic happen! ✨
